# 🚀 React Roadmap

A step-by-step guide to learn React from **beginner to advanced**.

📘 **Official Docs** → [https://react.dev](https://react.dev)

---

## ⚡ Getting Started with React

You can create a new React project using one of the following methods:

### 1. Using **Vite** (Recommended – Fast & Modern)

```bash
# Create project using Vite
npm create vite@latest my-app

# Select framework
React

# Select Variant
TypeScript

# Remaining select default

# Choose React or React + TypeScript
cd my-app

# Install dependencies
npm install

# Start development server
npm run dev
```

### 2. Using **Create React App** (Older but still works)

```bash
npx create-react-app my-app
cd my-app
npm start
```

## 1️⃣ Prerequisites

Before learning React, make sure you know:

- HTML (elements, forms, semantic tags)
- CSS (flexbox, grid, responsive design)
- JavaScript (ES6+ features)

  - let/const, arrow functions
  - template literals, spread/rest
  - array methods (`map`, `filter`, `reduce`)
  - destructuring
  - promises, async/await
  - import/export modules

---

## 2️⃣ React Fundamentals

- JSX & rendering elements
- Components (function vs class)
- Props & children
- State (`useState`)

- Conditional rendering
- Lists & keys
