# 🚀 React Roadmap

A step-by-step guide to learn React from **beginner to advanced**.

📘 **Official Docs** → [https://react.dev](https://react.dev)

---

## 1️⃣ Prerequisites

Before learning React, make sure you know:

* HTML (elements, forms, semantic tags)
* CSS (flexbox, grid, responsive design)
* JavaScript (ES6+ features)

  * let/const, arrow functions
  * template literals, spread/rest
  * array methods (`map`, `filter`, `reduce`)
  * destructuring
  * promises, async/await
  * import/export modules

---

## 2️⃣ React Fundamentals

* JSX & rendering elements
* Components (function vs class)
* Props & children
* State (`useState`)
* Event handling
* Conditional rendering
* Lists & keys

---

## 3️⃣ Core Hooks

* `useState` – local state
* `useEffect` – side effects
* `useContext` – global state
* `useRef` – DOM & persistent values
* `useReducer` – advanced state
* Custom hooks

---

## 4️⃣ Styling in React

* CSS Modules
* Styled-components / Emotion
* Tailwind CSS
* UI libraries (Material UI, Ant Design, Chakra UI, Shadcn)

---

## 5️⃣ Routing

* React Router v6+

  * Routes & `<Link>`
  * Nested routes
  * Protected routes

---

## 6️⃣ State Management

* Context API
* Redux Toolkit
* Zustand / Jotai / Recoil

---

## 7️⃣ Data Fetching

* Fetch API & Axios
* React Query (TanStack Query)
* SWR

---

## 8️⃣ Advanced React

* Performance optimization

  * `React.memo`, `useCallback`, `useMemo`
  * Code splitting & lazy loading
* Error boundaries
* Portals
* Rendering patterns (HOC, Render props, Compound components)

---

## 9️⃣ React + TypeScript

* Typing props & state
* Interfaces vs types
* Generics with hooks
* Context typing

---

## 🔟 React Ecosystem

* **Next.js** (SSR, SSG, API routes)
* **React Native** (mobile apps)
* Testing:

  * Jest + React Testing Library
  * Cypress / Playwright
* Storybook (UI component testing)

---

## 1️⃣1️⃣ Deployment

* Build tools: Vite / CRA

* Environment variables
